# Assignment 1: Association Between Dependent and Independent Variables

## Aim

To identify the association between dependent and independent variables using correlation analysis.

## Objective

To determine the relationship between students' study hours and their marks using the Pearson correlation coefficient.

## Variables

- Independent Variable: Study Hours
- Dependent Variable: Marks

## Dataset

A sample dataset containing students' study hours and their corresponding marks is used.

## Method Used

Pearson Correlation Coefficient is used to measure the strength and direction of the linear relationship between the two variables.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy

## Steps

1. Create the dataset.
2. Store the data in a Pandas DataFrame.
3. Calculate the Pearson correlation coefficient.
4. Calculate the p-value.
5. Interpret the association between the variables.
6. Visualize the relationship using a scatter plot and regression line.

## Result

The analysis shows a strong positive association between Study Hours and Marks. This indicates that, in the sample dataset, students who study for more hours tend to obtain higher marks.

## Conclusion

The Pearson correlation analysis successfully identifies the association between the independent variable (Study Hours) and dependent variable (Marks).
